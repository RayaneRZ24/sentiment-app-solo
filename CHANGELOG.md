# Journal des versions

Toutes les étapes solo ont été réellement rejouées le 28 octobre 2026, à partir des sources attribuées dans le README.

## 0.6.0 — TP6

Paquet sentiment_app, version unique, modèle configurable, commande sentiment, construction d'une roue et installation dans un venv neuf hors dépôt. L'API importe le paquet sans modifier sys.path. Le fichier de compatibilité conserve les anciens appels et les tests de panne.

## 0.5.0 — repère tp5-valide

Client HTTP, interface Streamlit, avis individuel et CSV ; douze tests de client et de page.

## 0.4.0 — repère tp4-valide

Validation Unicode, abstention, jeu d'or avec erreurs connues, intégration, typage, ruff, mypy et couverture minimale de 95 %.

## 0.3.0 — repère tp3-valide

API FastAPI, schémas Pydantic, six tests HTTP et modèle chargé au démarrage.

## 0.2.0 — repère tp2-valide

Génération des données, entraînement et évaluation reproductibles ; expériences de démonstration et Allociné consignées.

## 0.1.0 — repère tp1-valide

Structure, fiches reprises et vérifiées, environnement, attribution et adaptation explicite au travail individuel.
